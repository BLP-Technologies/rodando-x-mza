# Rodando x MZA

Aplicación para planificar recorridos peatonales accesibles en Mendoza y reportar
obstáculos en la vía pública. Incluye una app mobile (Expo / React Native), un
portal web de moderación (Next.js) y una API REST (Express 5 + PostgreSQL/PostGIS).
